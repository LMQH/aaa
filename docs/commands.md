# CLI 命令手册

本文只讲命令与启动参数的用法：怎么用、有什么用。

## 启动

```bash
PYTHONPATH=src python -m aaa            # 交互 REPL
PYTHONPATH=src python -m aaa -p "..."   # 单轮，只输出正文
echo "..." | PYTHONPATH=src python -m aaa --mode json
```

- 首次启动（没有任何渠道）进入渠道配置向导；非交互模式下改为报错退出。
- 已有配置则进入 REPL。状态行紧贴输入框上方，依次显示标识、模型、目录、Git、花费与上下文；输入框右侧在有空间时提示当前可用按键。TODO 树有内容时出现在输入区上方。

### 交互键位

| 操作 | 行为 |
|---|---|
| `Enter` | 空闲提交；运行中加入 FIFO 后续队列；已请求停止后提交的消息在运行确认取消后立即发送；补全菜单中先用 ↑↓ 选中才接受并执行命令名，参数与 `@` 文件只插入 |
| `↑` / `↓` | 补全菜单打开时移动选择，不碰历史；否则浏览历史 |
| `Tab` | 接受补全但不提交 |
| `Shift+Enter` | 插入换行，不发送；iTerm2/WezTerm/ghostty/VS Code 由 CLI 自动开启修饰键上报，无需配置。tmux 内默认会把 Shift+Enter 压成回车，需在 `~/.tmux.conf` 加 `set -s extended-keys on` 与 `set -as terminal-features "xterm*:extkeys"`（未配置时启动会提示）；kitty 与 macOS Terminal 不支持，需自行映射为 `Esc`+`Enter`。经 ssh 直连远端时终端类型不会传过去，Shift+Enter 不可用：改用 `Ctrl-J` 或 `Alt+Enter` 换行，或在远端套一层 tmux |
| `Ctrl-J` / `Alt+Enter` | 兼容换行 |
| `Esc` | 补全菜单打开时关闭；审批待决时拒绝；否则收起工具详情；运行中请求取消，草稿非空时改为打断并发送草稿 |
| `Ctrl-C` | 清空草稿（Up 取回）；窗口期内再次按下退出；审批时草稿为空则拒绝 |
| `Ctrl-D` | 空草稿空闲时退出 |
| `Ctrl-G` | `$VISUAL`/`$EDITOR` 编辑草稿，失败保留原稿 |
| `Alt+Up` | 从当前会话的暂停队列取回最近一条 |
| `Ctrl-O` | 展开/收起最近一次工具调用的完整参数与实际返回结果，不抢草稿焦点 |
| `PgUp` / `PgDn` | 补全菜单打开时按页移动；工具详情展开时按页滚动；报告面板内滚动内容；都不覆盖草稿 |
| 报告面板 | `/help`、`/todos`、`/skills`、`/insight`、`/trust`、`/usage` 以带边框和标题的全屏面板显示；`Esc` 关闭返回输入区，内容不写入滚动历史 |
| `Shift+Tab` | 空闲时循环权限模式 |

审批无需额外聚焦键：出现后 `↑`/`↓` 在「批准 / 拒绝」间移动，`Enter` 确认，`Esc` 拒绝；挂载后 500ms 内不接受确认，避免误放行。
打断并发出：运行中草稿非空时按 `Esc`，或先按 `Esc` 取消再提交消息，这条消息都会在运行确认取消后立即发出，不需要 `Alt+Up` 取回。发出时会附上打断前的请求与打断前已发生的工具调用，模型据此知道之前要做什么。运行没被取消（正常跑完）时按普通消息发出；取消未确认时消息留在队首，用 `Alt+Up` 取回。审批待决时 `Enter` 仍是「拒绝并排队」。

### 启动参数

| 参数 | 作用 |
|---|---|
| `message` | 位置参数，首条消息；非交互模式省略则从 stdin 读 |
| `-p`、`--print` | 单轮执行，只把助手正文写到 stdout 后退出 |
| `--mode interactive\|print\|json` | 输出形态；`json` 每行一个事件 |
| `-m`、`--model <引用>` | 本次运行使用的模型，支持 `渠道/模型` 与裸 id；歧义时报候选 |
| `--permission <模式>` | 本次运行的权限模式，取值同 `/mode` |
| `-c`、`--continue` | 续接当前目录最近可续聊的 Agent 会话 |
| `-r`、`--resume <ID>` | 按 id 或前缀续接 Agent 会话 |
| `--allow-shell` | 非交互模式下自动放行 `run_shell_command`（默认拒绝）；与 `--permission workspace-write` 搭配使用 |
| `--trust-repo` | 始终信任当前仓库的项目级可执行扩展（启动动画、记忆引擎、MCP 扩展），跳过交互确认 |

- `--model` 只影响本次运行，不改写默认模型。
- `-c` 与 `-r` 互斥。
- 退出码：`0` 成功，`1` 运行失败或被中断，`2` 用法/配置问题，`130` 被 Ctrl-C 取消。

### JSON 事件

`--mode json` 逐行输出，类型为 `model_start`、`content`、`tool_start`、`tool_done`、`tool_error`、`error`、`cancelled`、`confirm_required`、`confirm_approved`（带 `--allow-shell` 时），末行 `result`（含 `session_id`、`content`、`tokens`、`duration_s`、`error`）。每个事件带对应字段（`tool`、`args`、`duration_s`、`text`、`message`）。

### 委派

让主 Agent 创建并试跑一个 Agent、Team 或 Workflow 即可使用委派，不需要切换会话或使用斜杠命令。定义默认临时；需要复用时确认保存请求，之后的新会话可发现。委派中遇到需要确认的操作时，子任务拒绝并说明原因，不弹出子任务审批。取消会请求 Agno 停止已启动的子任务，但不会强制中断阻塞中的同步调用。

## 命令一览

| 命令 | 作用 |
|---|---|
| `/help` | 打印命令表 |
| `/provide` | 渠道编辑器：选渠道或新增，改协议、地址、Key、模型与窗口 |
| `/config` | 配置：无参打开设置面板（页签 / 分组 / 键值，`←→` 切页、`⏎` 改值、`⇥` 跳分组、输入即搜索、`Esc` 关闭）；`/config <键>` 查看；`/config <键> <值>` 修改；`/config start <动画名>` 切换启动动画 |
| `/model` | 切换模型：列表选择、`<渠道>/<模型>` 精确切换、`next` / `prev` 循环 |
| `/mode` | 切换权限模式（`read-only` / `workspace-write` / `danger-full-access`） |
| `/compact` | 立即压缩当前 Agent 会话 |
| `/usage` | 用量与花费：默认今天，`/usage week` / `/usage month` |
| `/insight` | 上下文分段占用（只读估算；运行中可查看） |
| `/memory` | 查看当前记忆引擎并切换（空闲时弹菜单，重启生效） |
| `/memory engine [引擎]` | 直达切换：关闭、内置或一个外置引擎，重启生效 |
| `/memory config [键] [值]` | 当前外置引擎的配置面：无参进菜单，键＋值直达修改（重启生效） |
| `/memory embedding [install]` | 嵌入增强安装与状态：install 后台安装增强包，权重下次启动自动下载 |
| `/session` | 会话操作菜单：切换/搜索/重命名/删除；`/session <id>` 直接切换；`rename`/`delete`/`search` 子命令直达 |
| `/todos` | 按阶段展示完整任务清单（全局编号） |
| `/export [路径]` | 导出当前会话为 Markdown（无参时确认预填路径） |
| `/redo` | 重新生成最后一轮已完成的回复 |
| `/edit <新消息>` | 从上一条用户消息分叉重发，原轮保留 |
| `/fork [轮次] [新消息]` | 回到某一轮之前：当前会话分叉成新会话并切过去，原句预填进草稿；带新消息则直接发送 |
| `/image <路径>` | 发送本地图片；支持的终端（iTerm2/WezTerm/kitty/Ghostty）里同时内联预览，其余终端打一行占位 |
| `/plugin [名称]` | 查看或启停 MCP 插件与技能包（重启生效）；名称同时是插件名和包名时先匹配插件 |
| `/skills` | 列出发现的技能，带来源与所属技能包 |
| `/new` | 新建会话（旧会话仍可从 `/session` 找回） |
| `/exit` | 退出；空输入处 Ctrl-D 等价 |

非斜杠输入交给模型；消息里的 `@路径` 在发送时附加文件：图片走图片通道，文本以 `<file>` 块拼进消息（上限 10 万字符，超出截断），目录与读不了的路径原样保留并提示。运行中的取消用 Esc，Ctrl-C 不清行外不终止运行。排队命令在下一轮重走同一分派器，不会被当作普通文本发给模型。命令清单（本表与补全菜单）按你的使用频次排序——次数多在前，同次数按字母 A→Z；频次记在本地 `~/.aaa/command_usage.json`，缺失或损坏时回退字母序。

## `/memory`：记忆引擎查看、切换与配置

- `/memory`：空闲时显示当前引擎与条目数并弹出引擎菜单；关闭时显示「记忆已关闭」＋菜单。Esc/Ctrl-C 取消不改动；运行中只显示状态。
- `/memory engine [引擎]`：直达切换，跳过菜单。可用 `off`、`builtin` 或 `external:<id>`；未知引擎拒绝且不改动。
- `/memory config [键] [值]`：当前外置引擎的配置面（分组 → 键 → 新值，密钥遮蔽显示）；键＋值直达修改。保存写进引擎自己的配置文件，重启生效。
- `/memory embedding [install]`：嵌入增强的安装与状态；install 后台执行（约 50MB，需要网络），模型权重在下次启动自动经镜像下载。
- 选择与配置只保存，重启后生效。运行中可以查看，修改需空闲；不迁移数据。


## `/provide`：渠道编辑

交互顺序固定：

1. 选择渠道（已有渠道列表 +「＋ 新增渠道」）。
2. 新增时输入渠道 id，只允许小写字母、数字、连字符；它同时是 `/model` 的前缀。
3. 选协议：`deepseek`（DeepSeek 原生）或 `openai-completions`（通用 OpenAI 兼容端点）。
4. Base URL。
5. API Key：留空沿用已保存的 Key。
6. 用 `GET /models` 探查模型；探查失败或返回空时改手输，逗号分隔。
7. 勾选启用的模型。
8. 逐个确认上下文窗口（tokens）。
9. 默认模型：现有默认仍有效则保留，否则从全部渠道的模型里选。

中途取消（Ctrl-C / 空输入）不写文件；保存后立即生效并切到默认模型。

## `/model`：模型切换

候选来自「已配置的渠道 × 模型」经 `enabled_models` 过滤后的范围。

| 输入 | 行为 |
|---|---|
| `/model` | 列表选择，默认高亮当前模型 |
| `/model gw/gpt-4o` | 精确切换 |
| `/model gpt-4o` | 只有一个渠道有该模型时直接切换 |
| 同名模型分布在多个渠道 | 报歧义并列出 `渠道/模型` 候选，不切换 |
| `/model next`、`/model prev` | 在范围内循环；不足两个时提示 |

切换成功即落盘为默认模型；会话不变，历史继续可用。`enabled_models` 目前只能手改 `secret.yaml`，空值表示全部模型可切换。

## `/mode`：权限模式

| 模式 | 文件工具 | Shell |
|---|---|---|
| `read-only`（默认） | 读、列目录、搜索 | 无 |
| `workspace-write` | 上行 + 写、编辑、移动 | 有，执行前确认 |
| `danger-full-access` | 上行 + 删除 | 有，无需确认 |

`/mode` 不带参数时弹选择菜单，带参数时校验取值。

### 执行确认

`workspace-write` 下模型请求 shell 命令时，本轮暂停并逐个询问：

```
  ? run_shell_command {"args": ["ls", "-la"]}
审批待处理：↑↓ 选择，Enter 确认，Esc 拒绝。
```

- 审批出现后 ↑↓/Enter/Esc 直接作用于审批，不需要 F2；挂载 500ms 后确认键才生效，防止误放行。
- 草稿仍可输入；草稿非空时按 Enter 表示「拒绝并发送这条消息」，不会误批准。
- 确认选中「批准」才放行；「拒绝」、Esc 与输入不可用都按拒绝处理。
- 同一「工具 + 参数」在本会话内批准一次后不再询问；换参数或换命令会重新询问。
- 拒绝会把拒绝结果回填给模型，本轮继续而不是报错。
- 非交互模式（`-p` / `--mode json`）无法提问，一律拒绝。
- 文件改动（write/edit/move）落盘前显示 diff：行级红绿，配对行的变化片段加强底色。

## `/todos`：任务清单

工具写入的清单按阶段分组展示；`[x]` 完成、`[>]` 进行中、`[ ]` 待办，编号为全局编号。同一会话最多一个进行中任务。

审批策略可经 `/config boundary.command_approval` 调整：`always`（默认，每条都问）/ `dangerous`（只问命中危险规则的命令，其余自动放行）。

## `/usage`：用量与花费

`/usage` 展示今天、`/usage week` 本周、`/usage month` 本月；周期按自然日/周（周一起）/月，本地时区。

```
今天 2026-11-18 · 用量与花费
  渠道      模型              输入   输出  缓存读    合计    金额
  --------  --------------  ------  -----  ------  ------  ------
  deepseek  deepseek-flash  128.0k  42.0k  980.0k  170.0k  $0.095
  --------  --------------  ------  -----  ------  ------  ------
  合计                      146.9k  48.5k  980.0k  195.4k  $0.116
```

- 行是 `(渠道, 模型)`，按 `输入 + 输出` 从高到低；没用过的模型不出现。
- 金额按价目表在入账时算好冻结；改价不影响历史。未定价的记录金额显示 `?`，不计入合计。

## `/insight`：上下文洞察

只读展示当前上下文的十层估算表：基础提示词、内置/自定义工具 schema、技能索引、记忆注入（指针，不重复计数）、压缩摘要、用户消息、工具调用、工具结果、推理、助手回复。

- 估算标注 ≈，计数与压缩阈值同源（Agno 选择链：HF tokenizer → tiktoken → 字符启发式）；缺席的段显示「无」。
- 最近一轮 usage 单列，不与估算混算；模型窗口未知时占比留空。
- 运行中可查看，不弹菜单、不改状态。

## `/session` 与 `/new`

- `/session` 空闲时弹会话操作菜单（切换/搜索/重命名/删除）；切换按更新时间倒序列出 Agent 会话，选中续聊。直达路径：`/session <id 或前缀>` 续聊，`rename`/`delete`/`search` 子命令直达（运行中不可用）。
- `/new` 新建 Agent 会话，不修改已有记录。
- `-c` 续聊当前目录最近的会话；`-r <id 或前缀>` 续聊指定会话。

## `/fork`：回到某一轮之前

- `/fork` 列出当前会话里已完成、带用户输入的轮次；选中某一轮即回到那一轮之前。
- 当前会话被整份复制成新会话，新会话只保留那一轮之前的对话，并切换过去；原会话不动，仍可从 `/session` 找回。被放弃的分支不会进入新会话的上下文。
- 不带新消息时，原句预填进草稿，改完回车发送；`/fork <轮次> <新消息>` 直接发送。
- 回到第 1 轮之前等同 `/new`。只针对最后一轮时，`/edit` 与 `/redo` 更轻。

## 平台

- macOS 与 Linux：表中键位均经实测。
- Windows：已实测可启动、跑完一轮对话、使用文件与命令工具、后台任务与打包；界面符号与图标与 macOS 一致，缺字时由终端字体决定显示。限制：真实终端里的按键未验证（CI 无法模拟按键），键位仍以 macOS 实测为准。后台任务停掉的是整棵进程树（Windows 用 Job Object，失败退回 `taskkill`）。
