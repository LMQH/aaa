# 自定义斜杠命令

一个 Markdown 文件就是一条命令，正文即提示词模板。

## 位置与命名

- 位置：`~/.aaa/commands/<命令名>.md`
- 命令名须匹配 `[a-z0-9][a-z0-9_-]*`，文件名去掉 `.md` 即为命令名。
- 启动时扫描一次，改完要重启 aaa。
- 不要与内置命令重名：内置命令优先，同名文件永远不会被调用。

## 最小示例

`~/.aaa/commands/review.md`：

```markdown
审查以下改动，按严重度列出问题；没有问题时明确回答“无问题”。

$ARGUMENTS
```

用法：`/review <粘贴的 diff>`。

## 参数替换

- `$ARGUMENTS` 会被替换为命令名之后的全部文本（已去掉首尾空白）。
- 模板里没有 `$ARGUMENTS` 时，用户追加的文本被丢弃。
- 没有参数时替换为空字符串，模板照常发送。

## 分派规则

- 提交 `/name ...` 时，先查内置命令；不在内置表里且命中自定义命令，模板即作为一条普通消息发往模型。
- 运行中提交自定义命令会进入 FIFO 队列，不会报错；排到它时按同一分派逻辑处理。
- 与内置命令同名的自定义命令在运行期也会被当作未知命令处理，不要依赖覆盖。

## 发现与确认

- 补全菜单会列出所有自定义命令（标注「自定义命令」）；`/help` 只列内置命令。
- 让 agent 创建时，它调用 `create_plugin(kind="command", name=..., content=...)`，每次写入都需要你确认。
- 也可以直接手写文件，效果相同。

## 生效

重启 aaa 后生效。命令模板不修改任何配置，不触发 Agent 重建。
