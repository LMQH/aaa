# 配置项

可调参数集中在 `~/.aaa/config.toml`，由程序维护，改动一律走 `/config`。

## 与 secret.yaml 的分工

- `config.toml`：除渠道、密钥、默认模型以外的全部可调项——记忆、压缩、超时、上限、默认权限模式、审批策略、日志、界面、会话。
- `secret.yaml`：只放渠道、密钥与默认模型，见 [渠道与模型](models-and-channels.md)。

## 三种用法

```text
/config                          # 分组菜单，逐层选择
/config ui.theme                 # 查询当前值、取值范围与可选值
/config ui.banner_animation sharingan # 精确设置
```

- 键名写错：提示「未知配置键」，不做任何修改。
- 值非法（超出范围、不在可选值里、类型不对）：提示原因并保留原值。
- 设置成功后立即写回整个文件。

## 生效档位

| 档位 | 表现 |
|---|---|
| 即时 | 保存后，下一次读取该值的地方生效 |
| runtime | 当场重建 Agent |
| 重启 | 提示「该配置在下次启动时生效」 |

具体键属于哪一档由程序提示决定，不靠记忆。

## 程序维护的事实

- 文件由程序全量重写，手工编辑留下的注释和顺序会被覆盖。
- 文件里出现非法值时，启动阶段回落默认并记警告，不阻止启动。
- 因此手工改文件只适合临时排查；常态修改请用 `/config`。

## 查看全部键

`/config` 的分组菜单就是键表：按 `ui`、`model`、`boundary`、`extensions`、`log`、`sessions` 等前缀分组，每项显示当前值与说明。

## 自定义提示词

- **只想补充偏好**：用 `~/.aaa/APPEND_SYSTEM.md`。例如写「回答尽量简短」，既能告诉模型你的偏好，又不移除 aaa 的默认指令。
- **想换掉默认角色和工作方式**：用 `~/.aaa/SYSTEM.md`。非空时整份替换 aaa 的默认指令，不只是换语气；「修改前先读相关文件」「保留无关改动」「如实报告验证结果和工具错误」等默认提醒也会随之移除。缺失或仅含空白时继续使用内置默认指令。

两个文件都是 UTF-8 Markdown，可同时使用：先采用默认指令或 `SYSTEM.md`，再追加 `APPEND_SYSTEM.md`。aaa 在构造 Agent 时读取这两个全局文件，不读取项目目录下的同名文件；编辑后重启 aaa 即可生效。

这两个文件不替换 Agno 生成的完整系统消息。当前权限模式、可用的 Shell 用法提示和已发现技能的目录仍会独立加入；工具可用性、审批、记忆和压缩仍由各自的配置与运行机制决定。

## 与其他扩展的关系

- 启动动画可用 `/config start <动画名>` 或通过配置键 `ui.banner_animation` 选择，见 [启动动画](animations.md)。
- MCP 超时用 `extensions.mcp_timeout` 调整，见 [MCP 扩展](mcp-extensions.md)。
- 界面主题用 `ui.theme`，可选值由程序提供，属于配置而非插件；新增主题需要改代码。
